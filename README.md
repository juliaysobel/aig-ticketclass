# IT Support Ticket Classifier

- AIG230NAA NLP Final Project (Transformer-Based Text Classification)
- Julia Ysobel Pineda

A text classification system that categorizes internal IT support tickets (Account,
Hardware, Network, Security, Software, etc.) using a fine-tuned DistilBERT model with a
custom classification head, compared against a TF-IDF + Logistic Regression baseline.
Built as both a graded NLP course deliverable and a portfolio piece for an upcoming IT
desktop support co-op.

## Dataset

[Console-AI/IT-helpdesk-synthetic-tickets](https://huggingface.co/datasets/Console-AI/IT-helpdesk-synthetic-tickets)
(Hugging Face, MIT license)
- 500 synthetic internal IT helpdesk tickets with subject,
description, category, and priority fields. Chosen specifically because it reflects
**internal** employee IT support (VPN, hardware, account access) rather than external
customer support, matching the intended real-world use case.

## Reproducing the Results

### 01: EDA & Preprocessing (local, no GPU needed)
Loads the raw dataset, explores category/priority distribution, text length, and
vocabulary, merges rare categories (threshold justified in-notebook), and saves a
stratified 70/15/15 train/val/test split to `data/`.

### 02: TF-IDF + Logistic Regression Baseline (local, no GPU needed)
Trains the baseline classifier on the same splits, saves the fitted vectorizer/model to
`models/baseline/`, and saves `results/baseline_results.json` for later comparison.

### 03: DistilBERT Fine-Tuning (**Google Colab, GPU required**)
1. Open in Colab, set runtime to **T4 GPU**
2. Edit the `REPO_URL` variable in the first cell to this repo's URL
3. Run all cells. This clones the repo, measures actual token lengths to set
   `MAX_LENGTH`, builds a custom classification head on top of pretrained DistilBERT,
   trains with a manual PyTorch loop, evaluates, and runs error analysis
4. The final cells save the model and copy it to Google Drive (see below)

### Getting the trained model onto your local machine
The fine-tuned model (~250MB+) is too large for GitHub and is not committed to this
repo. After running Notebook 3:
1. Download the `distilbert_model` folder from Google Drive
   (`it-ticket-classifier/distilbert_model`)
2. Place it locally as `models/distilbert/` in this repo (should contain
   `pytorch_model.bin`, `classifier_config.json`, and tokenizer files)

## Running the Inference App

Once `models/baseline/` (already in the repo) and `models/distilbert/` (downloaded per
above) are both in place:

```bash
python app.py
```

Open the local URL it prints (usually `http://127.0.0.1:7860`). Enter ticket text,
choose a model (fine-tuned DistilBERT or the baseline), and see the predicted category,
confidence scores, and a suggested routing team.
